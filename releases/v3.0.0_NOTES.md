# Pulex v3.0.0 Release Notes

**Release Date**: 2026-11-17  
**Publisher**: `HelloKittyXamKinLung`  
**Architecture**: Windows x64 Portable (`Tauri v2` + `Rust` + `DuckDB 1.2.2` + `Apache Arrow IPC`)

---

## Highlights in v3.0.0

### 1. Complete Functional Parity with Toad v2.6.0.3 on Tauri v2 + DuckDB 1.2.2
- **20-Line Smart Cell Expansion**: Upgraded `DataGrid` and `CellLineCalculator` to expand multiline forensic payloads up to 20 lines (`368px` ceiling with slim scrollbar), preserving active row expansion across virtual scrolling and modal overlays.
- **Persistent Derived Views (`Pulex Parse v3.0.0`)**: Fixed CTE `CREATE OR REPLACE VIEW` generation when `hasHeader` is enabled, added monotonic `_rx<N>` view naming, and persisted derived view definitions to `derived_views.json` for automatic replay across engine restarts.
- **Full `QueryExp` Compiler & Schema Dialect Parity**: Implemented `MapColumns` and `MapColumnsByIndex` operators, cross-slash Windows/UNC path normalization on `IN` / `NOT IN` filters, `dialect: "duckdb"` in `toadSchema` v2 metadata, `SUMMARIZE`-backed `StatsCache` histograms, and zero-row `limit = 0` schema probe fast paths.
- **Desktop Lifecycle & Export Pipeline**: Added native desktop menu bar (`File`, `View`, `Help`), single-instance CLI/file-association forwarding, multi-window dataset spawning, `.pulex`/`.toad`/`.tad` workspace save/load, and streaming Parquet / CSV / JSONL export.

### 2. Forensic Ingestion & Engine Resilience
- **16-Column EVTX Forensic Schema**: Expanded Windows Event Log extraction to 16 columns (`EventRecordID`, `TimeCreated`, `EventID`, `Level`, `LevelName`, `Provider`, `Channel`, `Computer`, `UserID`, `Param1`..`Param3`, `Binary`, `EventData`, `RawEvent`) with dual PascalCase/snake_case compatibility and `catch_unwind` isolation against corrupted chunks.
- **8 KB Binary Guard & Streaming UTF-16 / GZIP Transcoder**: Automatically blocks PE/ELF/ZIP/binary executables while transparently transcoding UTF-16LE, UTF-16BE, UTF-8 BOM, and multi-member `.gz` logs in 64 KB chunks.
- **Relational Database Browsing**: Added native read-only `ATTACH` support and table discovery for `.duckdb`, `.sqlite`, `.sqlite3`, and `.db` files.
- **Bounded DuckDB Worker Pool & Genuine Restart**: Enforced explicit worker memory caps (`2GB` default when `auto`), disk spill to `temp/`, `preserve_insertion_order = false`, and genuine connection pool reconstruction on `engine:do_restart`.

### 3. Security Hardening & Packaging Quality
- **Binary Hardening (`GUARD_CF`)**: Enabled Windows Control Flow Guard (`-C control-flow-guard=yes`, `--guard-cf`) alongside High-Entropy 64-bit ASLR and DEP/NX.
- **Embedded PE Resources**: Custom COFF `.rsrc` builder embedding 6-frame `RT_ICON` / `RT_GROUP_ICON` (`16px`..`256px`), `RT_VERSION` (`Pulex 3.0.0` / `HelloKittyXamKinLung`), and PerMonitorV2 DPI `RT_MANIFEST`.
- **WebView2 & IPC Security**: Removed inline HTML scripts and `innerHTML` error rendering, escaped hyperlink URLs (`he.encode`) with 4096-character ReDoS protection, restricted `open_url` to `http://` and `https://`, disabled production DevTools, and resolved all npm dependency advisories (`0` vulnerabilities).
- **Zero-Duplicate Release Layout**: Pruned legacy/duplicate binaries; `Pulex-3.0.0-x64-portable.zip` contains strictly `Pulex-3.0.0-x64-portable.exe`, `duckdb.dll`, and `WebView2Loader.dll`.
