## What's New & Fixed in v3.0.1

### 1. Toad v2.6.0.3 UI/UX & System-Call Parity
- **4-Menu Native Desktop Bar**: Completed `File`, `Edit`, `View`, and `Help` native menus (`Save As...`, `Export...`, `New Pulex Window`, `Open Example Dataset`, Undo/Redo/Copy/Paste/Select All) with cross-platform accelerators and dynamic window title synchronization (`<fileName> - Pulex`).
- **Toad Visual Parity**: Standardized `8pt Helvetica Neue` grid typography, default Light Mode theme, minimalist sidebar layout, and consistent file status badges.

### 2. WebView2 CSP & SlickGrid Rendering Fix
- **Resolved Row/Column Collapse in WebView2**: Removed inline `<style>` tags from `index.html` (moving base layout rules into compiled CSS) and configured explicit `style-src-elem` / `style-src-attr` CSP directives so Tauri v2 automatic nonce injection no longer blocks SlickGrid dynamic row/column rules (`0` CSP violations).

### 3. Forensic EVTX & Real-Time Ingestion Progress Engine
- **EVTX DuckDB SQL Projection Fix**: Double-quoted all EVTX projection identifiers (`"binary" AS "Binary"`) in `build_evtx_parquet_projection()` so Windows `.evtx` datasets load cleanly with all 22 columns (verified on `System.evtx` with `57,030` rows).
- **Eliminated EVTX Log Flooding**: Configured `tracing_subscriber::filter::Targets` with `evtx=warn` to suppress `56,000+` per-record `evtx::evtx_chunk` info lines per file (`0` spam lines).
- **Live `%` / `MB/s` / `ETA` Progress Telemetry**: Added Win32 `GetProcessIoCounters` I/O monitoring (`io_monitor.rs`), an 800 ms RAII `ProgressTickerGuard` during DuckDB `COPY`, full Toad-parity `toad:ingest-progress` payloads (`fileName`, `percent`, `speedMBs`, `etaSec`, `statusText`, `isOpen`), and `IngestionScheduler::wait_if_in_flight()` deduplication across foreground and background ingestion.
- **Zero-Copy UTF-8 BOM CSV Ingestion**: Skipped redundant full-file `.utf8_tmp.csv` copies for `UTF-8 BOM` CSV files (DuckDB `read_csv` strips BOM natively), saving 40 GB of unnecessary disk writes on multi-gigabyte Hayabusa/Excel exports.
