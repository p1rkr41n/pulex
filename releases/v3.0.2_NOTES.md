# Pulex v3.0.2 Release Notes

**Release Date**: 2026-11-20  
**Publisher**: `HelloKittyXamKinLung`  
**Architecture**: Windows x64 Single-File Portable (`Tauri v2` + `Rust` + `DuckDB 1.2.2` + `Apache Arrow IPC`)

---

## Highlights in v3.0.2

### 1. True Single-File Portable Executable (Zero Companion DLLs)
- **Delay-Loaded & Embedded Runtime DLLs**: Linked `duckdb.dll` and `WebView2Loader.dll` via `--delayload`, embedded gzip-compressed copies directly inside `Pulex-3.0.2-x64-portable.exe`, and added an atomic startup bootstrap (`runtime_dlls.rs`) that extracts them once into `pulexAppData_<id>\bin\` (automatically falling back to `%TEMP%\pulex_runtime_3.0.2\` when launched from a read-only directory) and registers the directory via `SetDllDirectoryW`.
- **Copy Anywhere & Run**: Copying `Pulex-3.0.2-x64-portable.exe` alone to any empty folder now launches cleanly with zero `STATUS_DLL_NOT_FOUND` errors.
- **Single-File ZIP Distribution**: `Pulex-3.0.2-x64-portable.zip` now contains strictly `Pulex-3.0.2-x64-portable.exe` with zero companion `.dll` files.

### 2. New Transparent Pulex Logo & Native Window Icon Fix
- **Transparent Pulex Icon Set**: Replaced all application PNG and multi-size ICO assets (`16px`, `24px`, `32px`, `48px`, `64px`, `128px`, `256px`) with the new transparent Pulex frog character and speed lines (outer white and dark circle backgrounds cleanly removed).
- **Resolved Tauri Default Window Icon Resource ID**: Updated PE `RT_GROUP_ICON` resource ID to `32512` (`IDI_APPLICATION`), ensuring the new transparent logo displays cleanly across Windows Explorer, Taskbar, Alt-Tab, and the application titlebar with zero icon-loader warnings.

### 3. Freeze Header Column (Sticky Column Headers on Vertical Scroll)
- **Main DataGrid (SlickGrid)**: Enforced a strict flex-column layout with sticky `.slick-header` (`z-index: 30`, strictly above 20-line expanded rows), opaque Light/Dark theme backgrounds, synchronized horizontal scroll alignment, and a subtle `.is-scrolled` drop shadow when scrolling downward.
- **Sidebar Project Files Table & RegexDialog**: Upgraded `NAME | DIRPATH | SIZE | STATUS` and Advanced Capture Groups table headers to sticky frozen headers so column names remain visible while scrolling long lists.

### 4. Regex Crash Fix, Plain-Text URL Safe Mode & Project / File Loading Integrity
- **Fixed Regex / SQL Fatal Panic (`toad:run_sql`)**: Fixed DuckDB 1.2.2 `Option::unwrap()` panic by executing DDL statements (`CREATE OR REPLACE VIEW`) via `execute_batch` and always calling `stmt.query([])` before inspecting `column_names()` via `rows.as_ref()`.
- **Strict Plain-Text URL Safe Mode (DFIR Security)**: All URLs in the DataGrid now render strictly as HTML-escaped plain text (never clickable `<a>` links) and cell clicks never launch external browsers, protecting analysts from accidental clicks on malicious URLs.
- **Fixed Project Lifecycle & File/Folder Loading**:
  - Eliminated duplicate `Untitled-1` creation after **Delete All Projects** by atomically seeding a single clean `Untitled-1` project inside `ParquetLedger::delete_all_projects()` and fixing `bridge.runtime` vs `bridge.engineName` checks in `ProjectWorkspaceManager.ts`.
  - Fixed `active_project_id` single-source-of-truth lookup in Rust (`get_active_project_id()`), `toad:ingest_file` payload key (`filePath`), `toad:stat_path` array response handling (fixing `File -> Add Folder` and Drag & Drop folders), and `toad:get_startup_args` CLI file opening.
  - Fixed premature `READY` status on un-ingested files (`PENDING` until Parquet cache exists), empty-project placeholder text, and auto-opening added files when the DataGrid is empty.

### 5. High-Speed Configurable Ingest & Large-Dataset Opening (~5.6x Faster CSV)
- **CSV 3-Tier Parallel-First Fallback & Native `.csv.gz`**: Switched CSV Tier 0 to `parallel = true` with automatic fallback to `parallel = false` (Tier 1) and `dirty_log` (Tier 2), configurable via `[duckdb] csv_parallel = auto|true|false`. UTF-8 `.csv.gz` streams directly via DuckDB native `compression = 'gzip'` with zero intermediate temp disk files.
- **Adaptive Auto CPU & RAM Budgeting**: Removed hardcoded 2-thread and 2GB worker caps. When `background_threads = auto` and `max_memory = auto`, exclusive large-file ingestion automatically scales to `max(2, logical_cores - 2)` threads and `clamp(2GB, 12GB, 25% total_system_ram)` via Win32 `GlobalMemoryStatusEx`, while dividing budgets proportionally across concurrent workers and strictly honoring explicit `config.ini` overrides.
- **Config-Driven Parquet, Parallel DirtyLog, EVTX Scaling & Auto-Sort Guard**:
  - Wired `[parquet] compression` (`snappy` default, or `zstd`/`gzip`/`uncompressed`) and `row_group_size` (`25000` default) live into CSV, JSONL, and DirtyLog `COPY` statements.
  - Added DuckDB parallel raw-line ingestion for `.log` files (`ingest_dirty_log_duckdb`) with automatic fallback to Rust line reader.
  - Scaled EVTX parser thread count dynamically via `resolve_worker_threads()`.
  - Added `[general] auto_sort_max_rows = 500000` (`0` = off, `-1` = always on) so opening multi-million-row datasets skips forced full-table `ORDER BY` stalls.
