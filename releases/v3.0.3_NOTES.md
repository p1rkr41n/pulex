# Pulex v3.0.3 Release Notes

**Release Date**: 2026-11-20  
**Publisher**: `HelloKittyXamKinLung`  
**Architecture**: Windows x64 Single-File Portable (`Tauri v2` + `Rust` + `DuckDB 1.2.2` + `Apache Arrow IPC`)

---

## Highlights in v3.0.3

### 1. Wide CSV & Multi-Line Quoted CSV Ingestion Hardening
- **RFC-4180 Quoted Newlines & Null Padding**: Added header column-count estimation (`estimate_header_column_count`) and automatic Tier-1 serial RFC-4180 fallback for wide or multi-line quoted CSV files (`csv_streamer.rs`), preventing corrupted column splits on complex DFIR forensic exports.
- **Native Gzip Zero-Temp Transcode**: Preserved native streaming `.gz` CSV ingestion with zero intermediate temp files and verified ZSTD/Snappy Parquet config support.
- **Force Reopen Cache Eviction**: `handle_get_table_name` (`query.rs`) now honors `forceReopen` / `force_reopen` by evicting stale cached Parquet files prior to re-ingestion.

### 2. Unlimited-Column CSV Parsing & Header Exclusion
- **Bypass DuckDB RE2 `{1000}` Limit**: `applyColumnExtraction` (`actions.ts`) now automatically switches to vectorized `TRIM(list_extract(str_split(...), idx), '"')` when extracting wide CSV datasets (`> 100` columns or index `>= 900`), delivering O(N) performance with unlimited columns.
- **"First Row is Header" Filtering**: `Parse Columns -> CSV` (`RegexDialog.tsx` & `actions.ts`) now cleanly excludes the original header row from extracted views when "First row is header" is enabled.
- **Materialized View Guard**: Ensures column extraction always targets a materialized DuckDB view (`tbl_*` / `main_table`), never a bare filename.

### 3. Includes All v3.0.2 Security, UX & Stability Fixes
- **Freeze Header Column**: Permanently pinned column headers across the Main DataGrid (with `.is-scrolled` drop shadow & `z-index: 30`), Sidebar Project Files Table, and RegexDialog Advanced Mode.
- **Strict Plain-Text URL Safe Mode**: All URLs in grid cells render strictly as HTML-escaped plain text and never open external browsers on click.
- **Regex / SQL Stability & Project Integrity**: Fixed DuckDB 1.2.2 `handle_run_sql` panic, duplicate `Untitled-1` on Delete All Projects, `active_project_id` SSOT, and folder/CLI loading.
